## 📊 Featured Project

### [U.S. Hospital Quality & ED Performance Analytics](https://github.com/bonggonzalez/cms-hospital-analytics)

An end-to-end analytics pipeline using public CMS data covering **5,419 U.S. hospitals**.

- Built a Python/pandas ETL pipeline and a validated three-table SQLite database with **138,084 hospital-measure records** and zero foreign-key violations
- Analyzed hospital ratings and emergency department performance using SQL joins, CTEs, and window functions
- Found that **Washington hospitals average 8.2% longer ED times** than hospitals elsewhere in the U.S., a gap that persists among hospitals of the same type

`Python` `pandas` `SQL` `SQLite` `Matplotlib` `Jupyter`
